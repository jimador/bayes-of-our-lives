Bayes of Our Lives is a Java refactor developed from the Decision Desk history and the example flow in [Embabel Tripper](https://github.com/embabel/tripper), inspected at base commit `002a08c`. The `BayesAgent` and `GuidePlaces` flow adapts Tripper's place-discovery and agent concepts. The root [LICENSE](LICENSE) covers original MIT-licensed Bays and Decision Desk work. Embabel Agent and Dice are dependencies with their own licenses.

The earlier copied Kotlin Tripper example and coastal Decision Desk demo were removed from the current tree during this refactor. Git history retains those files. No Tripper source repository was modified or pushed as part of this work.
