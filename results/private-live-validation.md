# Private live-data functional validation

On 2026-10-10/11 UTC, the same Embabel five-action agent completed with `--demo.mode=live --demo.destination='Miami, Florida'` under local, Jev, and OpenAI decision services. Each run resolved Miami through Open-Meteo, found one nearby mapped [Canoe/Kayak Launch (OSM node 3205380245)](https://www.openstreetmap.org/node/3205380245) through a bounded Nominatim search, and read Open-Meteo weather and marine forecast grids. The research card named that OSM lead and a 2026-10-11 01:00–03:00 UTC window. Reported forecast values at the sampled grid/hour were wind 8.1 kt, gust 14.4 kt, wave 1.969 ft, and modeled ocean current 0.108 kt. All three services returned proposition `false`, choice `review`, and projected rating `unknown`; all cards had status `research`. Jev identified its resolved model as `jev-1.13.0`, OpenAI as `gpt-4.1-mini`; finer versions were unreported. There were no typed model failures in these three runs. Each remote run made one mixed decision call and one classification call; no retry was configured for OpenAI. This is a functional check on one changing public forecast, not an accuracy or speed benchmark.

A second keyless live run with `--demo.destination='Lisbon, Portugal'` completed without the fixture city whitelist. The bounded place search yielded no nearby mapped launch, so the card explicitly named a **Lisbon forecast area (no mapped launch found)** and retained `research` status. It did not fabricate a launch. A Miami run with optional public `--demo.origin='Miami, Florida'` returned an OSRM base driving estimate of 11 minutes to the mapped lead. It still reported live traffic unknown, and the card remained `research`.

The live brief records geocoding, OSM, weather, and marine source URLs, place/grid coordinates, forecast sample time, and retrieval time. The marine `sea_level_height_msl` field is **not** a local MLLW tide prediction; the application leaves MLLW unknown. Mapped access is not confirmed open or suitable, and modeled ocean current is not a station-specific tidal-current prediction. No claim of a safe launch is made. The public providers may change or be unavailable; shared OSM services in particular returned HTTP 500/504 during the initial Overpass approach, so the implemented path uses one user-triggered Nominatim lookup with visible OSM attribution. Weather and marine APIs returned HTTP 200 in the completed runs.

The end-to-end live runs did not record split timing for geocoding/place lookup, weather/marine retrieval, remote model/network work, and local orchestration. Their observed numeric forecast values are time-sensitive and will change. The synthetic fixture timing tables elsewhere in `results/` must not be relabeled as live-data or provider benchmarks.
